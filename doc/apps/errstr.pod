=head1 NAME

errstr - lookup error codes

=head1 SYNOPSIS

B<openssl errstr> [B<-stats>] I<hex_error_code> ...

B<openssl errstr> B<-h>

=head1 DESCRIPTION

Sometimes an application will not load error message and only
numerical forms will be available. The B<errstr> utility can be used to 
display the meaning of the hex code. The hex code is the hex digits after the
second colon.

Each argument must contain a complete hexadecimal error code. A value with
an invalid suffix or an out-of-range value is rejected.

=head1 OPTIONS

=over 4

=item B<-stats>

print error string table statistics before decoding any error codes.

=item B<-h>, B<--help>

print a short usage summary.

=back

=head1 EXAMPLE

The error code:

 27594:error:2006D080:lib(32):func(109):reason(128):bss_file.c:107:

can be displayed with:
 
 openssl errstr 2006D080

to produce the error message:

 error:2006D080:BIO routines:BIO_new_file:no such file
